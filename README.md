# Celinna Jia Portfolio

A self-contained static portfolio website. No build step or package installation is required.

## Run locally

The simplest option is to open the folder in File Explorer and double-click `start-preview.cmd`. It starts the local server first, then opens the site at `http://127.0.0.1:8000`. Do not close the command window until you are finished.

Alternatively, from this folder, run either command below, then open `http://localhost:8000` in a browser:

```powershell
python -m http.server 8000
```

```powershell
npx serve .
```

## Pages

- `index.html` — Homepage, selected work, capabilities, about and contact
- `project-block.html` — Primary anonymous case study
- `goods-puzzle-3d.html` — Store visual, animated creative and localization case study

All portfolio artwork used by the pages is stored in `assets/`.
